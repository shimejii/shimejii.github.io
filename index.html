Rails 学習アウトプット — Google OIDC サインインの自前実装

GitHub で見る →

Rails Tutorial 完走後の学習アウトプットです。 認証ライブラリ（omniauth 等）に頼らず、Google アカウントによる OIDC（OpenID Connect）サインインを認可コードフローから自前実装した Rails アプリです。開発環境は Docker で構築しています。

目的

  • Rails Tutorial で学んだログイン機構とテーブル CRUD を、ゼロから再現して知識を定着させる
  • OIDC 認可コードフローを自分の手で実装し、「なぜその手順・対策が必要か」を理解する

利用技術

  • Ruby 3.4
  • Rails 8.1
  • Puma
  • PostgreSQL 17
  • Google OIDC（自前実装）
  • Docker / Docker Compose
